# The Pearl documentation

Pearl implements a variant of computational type theory like NuPRL, but it does so while emulating the behavior of intensional equality in proof assistants like Agda, Lean, or Rocq when the full semantic expressive power of computational type
theory is not needed. You can find some documentation in [https://github.com/bbentzen/pearl/blob/wip/doc/main.pdf]([https://github.com/bbentzen/pearl/blob/wip/doc/main.pdf]). Please note that this is work in progress.
